# Divisible-Room-Contracts

Fork of [Divisible-Room](../Divisible-Room/) that talks to the processor with **name-based CH5 contracts** instead of numbered joins. Same UI. Same Logic / Identity / Power Shutdown Confirmation S+ modules — rewire those to the GUI extender, not digital 21.

Do not use this folder for the join-based lab panel until the `.chd` is on the HTML5 XPanel.

## Contract artifacts

Generated by `npm run generate:contract` (`scripts/generate-contract.mjs`):

| File | Use |
|------|-----|
| [`contracts/divisible-room.cse2j`](contracts/divisible-room.cse2j) | CH5 mapping. Passed to `ch5-cli archive -c`. |
| [`public/config/contract.cse2j`](public/config/contract.cse2j) | Runtime copy (exact path CrComLib looks for). |
| [`contracts/divisible-room.chd`](contracts/divisible-room.chd) | SIMPL Windows **Manage GUI Extenders**. |

Signals are `Instance.Name`, for example `RoomA.Laptop`, `Walls.ABOpen`, `PowerConfirm.Initiate`.

## SIMPL

1. Copy Logic v1.0, Identity, and Power Shutdown Confirmation v1.0 as in Divisible-Room.
2. On each HTML5 XPanel: **Project → Manage GUI Extenders** → add `contracts/divisible-room.chd`.
3. Leave **Control Join Id** at 1–6 (Walls, Identity, PowerConfirm, RoomA, RoomB, RoomC).
4. Wire extender **inputs** (FB to panel) from Logic/Identity/Shutdown outputs.
5. Wire extender **outputs** (presses from panel) to Logic/Shutdown inputs.

Do **not** also connect numbered joins 1–47 on that XPanel for these signals.

Details: [`docs/simpl.md`](docs/simpl.md). Signal list: [`docs/CONTRACT-MAP.md`](docs/CONTRACT-MAP.md).

## Run

```bash
cd Divisible-Room-Contracts
npm install
npm run generate:contract
npm run dev
```

Vite is **http://localhost:5175** (join-based Divisible-Room stays on 5174).

```bash
npm run build:ch5z
```

Processor URL (after deploy):

```
https://192.168.86.200/divisible-room-contracts/index.html?ipID=E1&authToken=<token>
```
